# Tegash: аудит состояния на 23 ноября 2026

Это обзор текущего репозитория и результатов локальных проверок, а не полная
независимая проверка безопасности или подтверждение всех сценариев на устройстве.

## Приоритетные незавершённые проверки

1. Ручной экспорт сообщений и участников работает в жизненном цикле Activity:
   `onDestroy` останавливает исполнитель. При закрытии процесса или нехватке
   памяти экспорт может прерваться. Для надёжной фоновой работы нужен отдельный
   подходящий Android foreground service с восстановлением состояния.
2. Запланированный экспорт использует сохраняемый JobScheduler с требованием
   сети. Android может перенести или прервать работу, а после принудительной
   остановки приложения запуск ограничен системой. Проверить реальные запуск,
   перезагрузку телефона, ограничения батареи и поведение при длительном экспорте.
3. SMTP с TLS, отправка уведомлений и открытие системного меню отправки покрыты
   частичными проверками, но полный сценарий с реальной почтой и разрешениями
   конкретного телефона не подтверждён. Удаление писем по сроку не реализовано:
   SMTP не управляет содержимым почтового ящика.
4. Удаление личного чата и выход из группы отправляют действие в Telegram после
   подтверждения. Проверить вручную на специально созданных тестовых чатах;
   автоматические проверки не выполняют такие действия в реальном аккаунте.
5. При аудите в черновике Android-релиза находился старый APK: загрузка
   исправленной сборки была прервана. При публикации необходимо заменить APK
   и сопоставить номер сборки, тег и исходный коммит. Черновики не участвуют
   в проверке обновлений приложения.
6. Приложение Android пока собирается только для arm64 и подписывается debug-ключом.
   Для публичного релиза нужна постоянная release-подпись и проверенный путь обновления.
7. Иконки Windows включены в EXE, собранный через Wine; Linux-иконка включена
   в исходный пакет. Отображение ярлыков и работа EXE на Windows и Linux ещё
   требуют проверки на целевых системах. Функциональность платформ не синхронизирована.
8. В корне подготовлены некоммерческие условия, однако существующий desktop-код
   ранее опубликован под MIT. Новые условия не отменяют прежнюю выдачу прав и
   не меняют лицензии зависимостей; область действия следует проверить с владельцами прав.

## Выполненные проверки

- Android: debug APK собран и установлен на подключённое устройство; 52 Python
  backend-теста прошли. Полная визуальная проверка нового окна экспорта не завершена.
- Desktop: 269 тестов прошли, один пропущен; Windows x64 EXE собран в Wine.
- Выполнена проверка `git diff --check`. Архив с исходными иконками и `.kotlin/`
  исключены из Git.
- GitHub содержит два черновика: Android и desktop. Они не являются опубликованными
  стабильными релизами.
