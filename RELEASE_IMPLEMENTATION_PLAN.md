# Tegash: иконки, обновления и релизы

1. Разобрать архив иконок, исключить исходный ZIP из Git, подключить ресурсы Android, Windows и Linux; проверить сборки.
2. Показывать дату последней активности в списке чатов и добавить подтверждаемое удаление или выход из неактивного чата, не скрывая ошибки Telegram.
3. Уточнить область действия некоммерческой лицензии с учётом уже опубликованной MIT-лицензии и прав авторов зависимостей.
4. Добавить безопасную проверку новых GitHub Releases и предложение открыть страницу загрузки, без автоматической установки.
5. Проверить фактические Android, Linux и Windows сборки, подготовить версии и описание изменений, затем опубликовать проверенные артефакты в GitHub Releases.
6. После этого синхронизировать функциональность и номера версий платформ, протестировать обновление между релизами и документировать оставшиеся расхождения.
